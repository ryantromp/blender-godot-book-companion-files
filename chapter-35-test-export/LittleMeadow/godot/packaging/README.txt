Little Meadow 1.0.0
===================

A small farm, a long summer. A game made with Godot 4.7 and Blender, built as the project of the book "Little Meadow".

How to start
------------
Linux:    unzip the folder, then run LittleMeadow.x86_64 (the .pck file must stay next to it).
          If the file does not start, make it runnable first: chmod +x LittleMeadow.x86_64
Windows:  unzip the folder, then double-click LittleMeadow.exe.
          Windows may show "Windows protected your PC" because this build is not signed.
          Choose "More info", then "Run anyway".

How to play
-----------
Click the ground to walk, click a thing to use it.
1 Hoe, 2 Seeds, 3 Watering can, 4 Hands.
B builds fences and props. I opens the bag.
Q and E turn the camera, the mouse wheel zooms.
F5 saves quickly, F9 loads quickly, F10 opens the save window.
Esc pauses the game and opens the menu.

Where the game keeps your files
-------------------------------
Linux:    ~/.local/share/godot/app_userdata/Little Meadow/
Windows:  %APPDATA%\Godot\app_userdata\Little Meadow\
macOS:    ~/Library/Application Support/Godot/app_userdata/Little Meadow/
The folder holds settings.cfg and a saves folder with one slot_N.json file per saved game.
To start again from nothing, close the game and delete that folder.
