LITTLE MEADOW: THIRD-PARTY NOTICES
==================================

This file belongs with every copy of the game Little Meadow 1.0.0. It names the work of others that the game
contains and the licence of each. The credits window of the game (Credits on the title screen) shows the same
list in short form.

Files next to this one:
  LICENSE-GODOT.txt     the permission notice of the Godot Engine (MIT licence), word for word
  COPYRIGHT-GODOT.txt   the licence overview of the Godot Engine source, word for word, with the full text of
                        every licence it names
  README.txt            how to start and play

1. Godot Engine 4.7.2
---------------------
The game program (LittleMeadow.x86_64 or LittleMeadow.exe) contains the Godot Engine. It is built from the
source of Godot 4.7.2 stable (commit ed1daf0bf001b61586d9930840f2f1394092c079, https://godotengine.org).
Copyright (c) 2014-present Godot Engine contributors.
Copyright (c) 2007-2014 Juan Linietsky, Ariel Manzur.
Licence: MIT. The permission notice is in LICENSE-GODOT.txt and must stay with every copy.

The engine contains libraries of other authors. COPYRIGHT-GODOT.txt, copied from that source, lists every
library with its copyright and licence and ends with the licence texts. Six of its entries, as written there:

  FreeType      1996-2025, David Turner, Robert Wilhelm, and Werner Lemberg. Licence: FTL
  HarfBuzz      Google, Inc., Behdad Esfahbod, Red Hat, Inc. and others (the list is in the file). Licence: HarfBuzz
  Jolt Physics  2021, Jorrit Rouwe. Licence: Expat (MIT)
  libpng        1995-2026, The PNG Reference Library Authors and others. Licence: Zlib
  Mbed TLS      The Mbed TLS Contributors. Licence: Apache-2.0
  zlib          1995-2026, Jean-loup Gailly and Mark Adler. Licence: Zlib

The file covers all libraries of the source tree. Which of them the program uses depends on the modules the
build switched on.
