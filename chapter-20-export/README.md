# Chapter 20: Optimise and Export

Part 2: Blender, Asset Creation

## How to use this folder

Copy the contents of the `LittleMeadow` folder in here into your own `LittleMeadow` folder, keeping the subfolders. Files with the same name are replaced. You can also use it only to compare your own work with the book's.

## Blender files built in this chapter

- `LittleMeadow/blender/lm_export.blend`.
- `LittleMeadow/blender/scripts/lm_assets.json`.
- `LittleMeadow/blender/scripts/lm_build_export.py`.
- `LittleMeadow/blender/scripts/lm_check_assets.py`.
- `LittleMeadow/blender/scripts/lm_proxies.py`.
- `LittleMeadow/export/` (67 `.glb` files, the Blender export). Chapter 23 imports the same files into Godot.
