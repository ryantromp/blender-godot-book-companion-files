# Chapter 14: The Farmer: A Low-Poly Character Ready for a Skeleton

Part 2: Blender, Asset Creation

## How to use this folder

Copy the contents of the `LittleMeadow` folder in here into your own `LittleMeadow` folder, keeping the subfolders. Files with the same name are replaced. You can also use it only to compare your own work with the book's.

## Blender files built in this chapter

- `LittleMeadow/blender/lm_farmer.blend`. This is the finished version. Later chapters keep working in this file (16, 17, 20), so it can already hold work you have not reached yet.
- `LittleMeadow/blender/scripts/lm_apply_char.py`.
- `LittleMeadow/textures/T_char_atlas.png`.
